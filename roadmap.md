# Project Roadmap

## Active Tasks

1. Disconnect Lovable Cloud from the project (user confirmed; irreversible and deletes all cloud data)
   - Status: must be done by user in Project Settings → Integrations → Lovable Cloud → Disconnect
   - Note: no agent tool can disconnect Lovable Cloud; it is a manual workspace/project action
2. Connect a user-owned Supabase project to the app
   - Status: available only after Lovable Cloud is disconnected
   - Path: Project Settings → Integrations → Supabase → OAuth connect
   - Note: no agent tool exists for external Supabase connect; user must complete OAuth flow in UI
